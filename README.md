# GameMimo — Official Interactive Web Portal & Landing Page

> **Brand**: GameMimo (Casual & Family-Friendly Gaming Division of SGGame)  
> **Live Target**: [https://gamemimo.com](https://gamemimo.com) & [https://www.sggame.us](https://www.sggame.us)  
> **Tech Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, DaisyUI v5, Lucide Icons, Framer Motion, Canvas Confetti

---

## 🌸 Overview

This repository contains the interactive, high-performance web portal and landing page for **GameMimo**. It showcases the studio's full 2026–2027 game portfolio, seasonal LiveOps events, instant browser playable game demos, studio story, and compliant legal policy pages.

---

## 🌟 Key Features

1. **Parallax Hero with Mascot Physics**:
   - Animated floating baby dragons, fluffy kittens, red biplanes with smoke trails, and magic sparkling gems.
   - Interactive haptic tap arena triggering celebratory particle confetti bursts.
2. **Interactive Game Showcase & Catalog**:
   - Filterable tabs: `All`, `Q4 2026 Lineup`, `Holiday Specials`, `2027 Upcoming`, and `Playable in Browser`.
   - Rich game cards with engine tags (Unity 6, Cocos Creator 3.8, React + Pixi.js), store badges, and interactive playable modal launcher.
3. **Seasonal Holiday Events (LiveOps)**:
   - 🎃 *Halloween Night: Spooky Sweets 3D Match* (October 2026).
   - 🎄 *Christmas Wonder: Santa's Gift Merge* (December 2026).
   - 🌸 *Celestial Dragon Sanctuary Hatching Gala* (Q1 2027).
4. **Studio Story & Global Footprint**:
   - Tracing the studio's journey from Hanoi (2015) to Los Angeles (2019) and Atlanta, GA headquarters (2020–2026).
   - Connected multi-domain network switcher: `sggame.us`, `gamemimo.com`, `umindchannel.com`, `bintv.us`, `binbontv.com`.
5. **Theme Switcher**:
   - Support for multiple cute themes: `pastel`, `cupcake`, `valentine`, `emerald`, `sunset`, and `cyberpunk`.
6. **Compliance & Legal Pages**:
   - Links to hosted COPPA Child Safety Declarations, GDPR/CCPA Privacy Policy, and Terms of Service.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ / 20+
- `pnpm`

### Installation & Development
```bash
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

---

## 📦 Deployment

- **Cloudflare Pages / Edge**: Built statically to `dist/` and served via Cloudflare Pages with edge caching and Brotli compression for sub-second load times globally.
- **Apex Domain**: `https://gamemimo.com`
